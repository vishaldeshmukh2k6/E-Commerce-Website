## 🏬 Overview  

This project is a **Flask-based E-Commerce web application** that delivers a complete online shopping experience — with **user management**, **product control**, and **payment gateway integration**.  
Optimized for performance using **Gunicorn**, designed for scalability, and built for real-world deployment.  

---

## ✨ Key Features  

### 👥 User / Customer
- 🔐 **Secure Login & Registration**
- 🔑 **Password Reset via Email**
- 🔍 **Instant Product Search**
- 🛒 **Cart Management (Add / Update / Remove)**
- 💳 **Integrated Payment Gateway**

### 🧑‍💼 Admin Panel
- 📦 **Add / Edit / Delete Products**
- 📊 **Stock & Availability Control**
- 🚚 **Order Tracking & Status Updates**
- 💬 **Customer & Order Overview**

### ⚙️ System Features
- 🧰 **Modular Flask App Architecture**
- ⚡ **Gunicorn for High-Performance Deployment**
- 💾 **Database-Driven (SQLite / PostgreSQL)**
- 🌈 **Easily Customizable and Scalable**

## 🔍 How It Works  

1. 👤 **User** registers or logs in securely.  
2. 🛍️ **Browses** and adds products to the cart.  
3. 💳 **Checks out** with integrated payment options.  
4. 🧑‍💼 **Admin** manages inventory and orders through a dashboard.  
5. ⚙️ **Flask + Gunicorn** ensure smooth, scalable performance.
